Gemini access

Create a Gemini API key in Google AI Studio. Required to adapt. Not written to disk. Session storage is used only if you check the box below.

How to connect Gemini 3.8 Flash
  1. Open Google AI Studio API keys and sign in with the Google account that should be billed.
  2. Create an API key in a Google Cloud project. If prompted, enable the Gemini API (Generative Language API) for that project.
  3. Paste the key in the field above. Leave Model on Gemini 3.8 Flash. The Google API id is gemini-3.8-flash.
  4. Do not type Cursor names such as gemini-3.8-flash-medium into Custom model. Those are not valid Google API ids.
  5. If this page cannot reach Google from the browser, run python3 scripts/serve_adapter.py and set the proxy to http://127.0.0.1:8000/api/gemini.

Use Gemini 3.8 Flash unless an older key cannot call that model.

Blank output — check original pages

Gemini returned no text for this batch. That can mean the source pages are blank, or that the model missed printed content. Compare the original pages, then skip them if they are blank or retry if they have lesson text. Retry tells Gemini a reviewer confirmed printed text, so it must transcribe these pages instead of returning empty. Remaining pending batches wait until you choose.
